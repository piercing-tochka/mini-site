# Пирсинг Точка — готовый сайт

Эта папка содержит готовую статическую сборку для хостинга.

## Публикация

Загрузите содержимое папки `dist` на хостинг целиком, сохранив папку `assets`. Главная страница — `index.html`. Настройка сборки и установка зависимостей не требуются.

Внутри есть главная, обе страницы студий и личные страницы Алёны, Юлии и Наталии. Переключение темы, меню, ссылки и онлайн-запись работают через `script.js`.

Изображения оптимизированы и сохранены в WebP. Шрифты подгружаются из Google Fonts; если они недоступны, используются системные шрифты.
