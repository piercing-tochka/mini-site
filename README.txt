# Пирсинг Точка — готовый сайт

Все страницы, стили, скрипты и изображения лежат в этой папке на одном уровне. Для загрузки выберите все файлы внутри `dist` и отправьте их в корень репозитория GitHub. Не создавайте подпапки.

Главная страница — `index.html`. В сборке есть страницы обеих студий и мастеров Алёны, Юлии и Наталии. Изображения оптимизированы в WebP. Настройка сборки не требуется.
